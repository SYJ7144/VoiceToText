# EnKorTranslator

음성 파일을 창에 끌어다 놓으면 텍스트로 전사해 `.txt` 파일로 저장하는 GUI 프로그램입니다.
로컬 Whisper(`faster-whisper`) 기반이라 한국어·영어 음성을 인터넷 연결 없이 오프라인으로 전사할 수 있습니다.

## 주요 기능

- **로컬 실행**: 로컬 Whisper(`faster-whisper`)를 사용하므로 인터넷 없이 동작하고, 파일이 외부로 전송되지 않습니다.
- **드래그앤드롭**: 파일(또는 폴더)을 여러 개 끌어다 놓으면 순서대로 처리합니다.
- **출력**: 원본 음성과 같은 위치에 같은 이름의 `.txt` 파일을 만듭니다. 각 구간 앞에 시작 시각이 `(0:42)` 형태로 붙습니다 (예: `(0:42) Okay good afternoon`).
- **지원 형식**: mp3, wav, m4a, aac, flac, ogg, opus, mp4, mov, mkv, webm 등 (ffmpeg 별도 설치 불필요)
- **언어 선택**: 자동 감지, 한국어, 영어, 일본어, 중국어 중 선택 가능

## 실행 방법

### 가장 쉬운 방법 (macOS)

Finder에서 `run.command`를 더블클릭합니다. 최초 실행 시 자동으로 가상환경을 만들고 필요한 패키지를 설치합니다.

> 처음 더블클릭 시 "확인되지 않은 개발자" 경고가 나오면, 파일을 우클릭 → **열기**를 한 번 선택하면 됩니다.

### 터미널에서

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/python transcribe_gui.py
```

## 사용법

1. 프로그램을 실행합니다.
2. (선택) 상단에서 **모델**과 **언어**를 고릅니다.
3. 음성 파일을 가운데 영역에 끌어다 놓거나, 우측 상단 **파일 선택…** 버튼을 누릅니다.
4. 진행률이 100%가 되면 결과가 화면에 표시되고, 음성 파일 옆에 `.txt`로 저장됩니다.

## 모델 선택 기준

| 모델 | 최초 다운로드 | 속도 | 정확도 |
|------|------|------|------|
| `tiny` | ~75 MB | 매우 빠름 | 낮음 |
| `base` | ~145 MB | 빠름 | 보통 |
| `small` | ~490 MB | 보통 | 좋음 (기본값) |
| `medium` | ~1.5 GB | 느림 | 매우 좋음 |
| `large-v3` | ~3 GB | 매우 느림 | 최고 |

한국어는 `small` 이상을 권장합니다. 모델은 처음 한 번만 내려받고 이후에는 `~/.cache/huggingface`에 캐시됩니다.

## 요구 사항

- Python 3.9 이상
- [requirements.txt](requirements.txt)에 명시된 `faster-whisper`, `tkinterdnd2`

## 참고

- Apple Silicon에서도 GPU 가속은 지원되지 않아 CPU로 동작합니다. 긴 파일은 시간이 걸릴 수 있습니다(대략 오디오 길이의 0.3~1배).
- 언어를 "자동 감지"로 두면 첫 30초로 언어를 추정합니다. 결과가 이상하면 언어를 직접 지정하세요.
