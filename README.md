# VoiceToText

음성 파일을 올리거나 브라우저에서 바로 녹음하면 텍스트로 전사해주는 서비스입니다.
로컬 Whisper(`faster-whisper`) 기반이라 외부 유료 API 없이 동작합니다. **웹 버전**과 기존 **데스크탑 GUI 버전**을 함께 제공합니다.

## 웹 버전 (`app/`)

- **로그인 없이 바로 사용**: 파일 업로드/녹음/전사/다운로드는 로그인이 필요 없습니다.
- **브라우저 녹음**: 마이크로 바로 녹음해서 업로드할 수 있습니다.
- **타임스탬프 동기 재생**: 전사 결과에서 구간을 클릭하면 오디오가 해당 지점으로 이동해 재생되고, 재생 중인 구간이 자동으로 하이라이트됩니다.
- **다양한 내보내기**: `.txt`, `.srt`(자막), `.vtt`(자막) 형식으로 다운로드할 수 있습니다.
- **히스토리 저장(로그인 시에만)**: 구글 또는 카카오 계정으로 로그인하면 전사 결과(텍스트)를 서버에 저장하고 나중에 다시 볼 수 있습니다. 로그인하지 않으면 그 세션에서만 결과를 볼 수 있습니다.
- **한국어 / English UI**: 우측 상단 버튼으로 전환, 선택한 언어는 브라우저에 저장됩니다.
- **다크 모드**: 시스템 설정을 따르거나 직접 전환할 수 있고, 선택값은 브라우저에 저장됩니다.
- **모바일 대응**: 반응형 레이아웃으로 휴대폰에서도 사용할 수 있습니다.
- **프라이버시**: 업로드된 원본 음성 파일은 전사가 끝나는 즉시 서버에서 삭제됩니다. 로그인 후 저장하는 히스토리에는 **전사된 텍스트만** 남고 음성 파일은 남지 않습니다.

### 실행 방법

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env   # 아래 "로그인 설정" 참고 (안 채워도 전사 기능은 바로 작동합니다)
./venv/bin/uvicorn app.main:app --reload
```

브라우저에서 http://localhost:8000 접속.

### 구글 / 카카오 로그인 설정

전사 기능 자체는 로그인 없이 바로 동작하지만, **히스토리 저장/조회**를 쓰려면 OAuth 클라이언트를 등록하고 `.env`에 값을 채워야 합니다. 둘 다 무료입니다.

**구글**
1. [Google Cloud Console](https://console.cloud.google.com) → "API 및 서비스" → "사용자 인증 정보" → "OAuth 클라이언트 ID" 생성 (유형: 웹 애플리케이션)
2. 승인된 리디렉션 URI에 `http://localhost:8000/auth/google/callback` 추가 (배포 후에는 실제 도메인도 추가)
3. 발급된 클라이언트 ID/SECRET을 `.env`의 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`에 입력

**카카오**
1. [Kakao Developers](https://developers.kakao.com) → 애플리케이션 추가 → "카카오 로그인" 활성화
2. Redirect URI에 `http://localhost:8000/auth/kakao/callback` 추가
3. 동의 항목에서 닉네임/이메일 활성화
4. REST API 키와 클라이언트 시크릿을 `.env`의 `KAKAO_CLIENT_ID`, `KAKAO_CLIENT_SECRET`에 입력

값을 채우지 않으면 로그인 버튼을 눌렀을 때 "로그인 기능이 아직 설정되지 않았습니다" 안내만 뜨고, 전사 기능은 그대로 사용할 수 있습니다.

### 배포 시 참고

- 무료/저사양 호스팅(Render, Railway, Fly.io 등)을 가정해 전사 작업은 **한 번에 하나씩 순차 처리**됩니다 (`app/jobs.py`). 동시 사용자가 많다면 워커 수를 늘리거나 큐를 분리하세요.
- `SESSION_SECRET_KEY`는 배포 환경에서 반드시 임의의 값으로 바꾸세요.
- 데이터는 `data/app.db`(SQLite, 사용자/히스토리 텍스트)와 `data/uploads/`(처리 중인 임시 음성, 처리 후 자동 삭제)에 저장됩니다. 영속 디스크가 없는 플랫폼이라면 SQLite 대신 외부 DB 연결을 고려하세요.

### 법적/프라이버시 참고

- faster-whisper(및 Whisper 모델)는 MIT 라이선스라 상업적 배포에 문제 없습니다.
- 실제 리스크는 "타인의 목소리가 담긴 녹음을 동의 없이 업로드하는 경우"입니다. 서비스를 공개 배포한다면 이용약관에 "제3자 음성이 포함된 파일은 당사자 동의하에만 업로드" 조항을 명시하고, 개인정보처리방침을 게시하는 것을 권장합니다.
- 위 "원본 음성 자동 삭제" 정책이 이 리스크를 상당 부분 줄여줍니다.

## 데스크탑 GUI 버전 (`desktop/`)

기존 Tkinter 기반 드래그앤드롭 앱입니다. 인터넷 연결 없이 완전히 로컬에서 동작합니다.

Finder에서 `desktop/run.command`를 더블클릭하거나:

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/python desktop/transcribe_gui.py
```

## 모델 선택 기준

| 모델 | 최초 다운로드 | 속도 | 정확도 |
|------|------|------|------|
| `tiny` | ~75 MB | 매우 빠름 | 낮음 |
| `base` | ~145 MB | 빠름 | 보통 |
| `small` | ~490 MB | 보통 | 좋음 (기본값) |
| `medium` | ~1.5 GB | 느림 | 매우 좋음 |
| `large-v3` | ~3 GB | 매우 느림 | 최고 |

한국어는 `small` 이상을 권장합니다. 모델은 처음 한 번만 내려받고 이후에는 `~/.cache/huggingface`에 캐시됩니다.

## 참고

- Apple Silicon에서도 GPU 가속은 지원되지 않아 CPU로 동작합니다. 긴 파일은 시간이 걸릴 수 있습니다(대략 오디오 길이의 0.3~1배).
- 언어를 "자동 감지"로 두면 첫 30초로 언어를 추정합니다. 결과가 이상하면 언어를 직접 지정하세요.
